## 🔐 REQUIRED ENVIRONMENT VARIABLES

These variables are **REQUIRED**. The application will fail to build/run without them in production.

### 1. Database Configuration

**DATABASE_URL**
- **Value:** Your Supabase PostgreSQL connection string
- **Format:** `postgresql://user:password@host:5432/database`
- **Example:** `postgresql://postgres.xxx:password@aws-1-sa-east-1.pooler.supabase.com:5432/postgres`
- **Where to get it:** Supabase Dashboard → Settings → Database → Connection String (Pooler)
- **Environments:** Production, Preview, Development

**DIRECT_URL**
- **Value:** Same as DATABASE_URL (for Supabase)
- **Format:** `postgresql://user:password@host:5432/database`
- **Note:** Some providers need different URLs for pooled vs direct connections
- **Environments:** Production, Preview, Development

### 2. Security Secrets

**JWT_SECRET** ⚠️ CRITICAL
- **Value:** Strong random secret (32+ characters)
- **Generate:** `npx tsx scripts/generate-secrets.ts`
- **Example:** `4yEkhiFDCWz/UQOMF580DL6tBQ1gXSRNxaEcUFjEYXw=`
- **Validation:** App will throw error if not configured in production
- **Environments:** Production, Preview, Development

**PIN_SALT** ⚠️ CRITICAL
- **Value:** Strong random salt (32+ characters)
- **Generate:** `npx tsx scripts/generate-secrets.ts`
- **Example:** `9ByiA/u/fNxlNFlSlp5FoljeDhRtBYZ6UgfMvaMVCAg=`
- **Validation:** App will throw error if not configured in production
- **Environments:** Production, Preview, Development

### 3. Tenant Configuration

**TENANT_ID**
- **Value:** Your tenant UUID
- **Default (MVP):** `a1b2c3d4-e5f6-7890-abcd-ef1234567890`
- **Note:** For MVP, use the default. For multi-tenant, generate unique UUIDs per tenant
- **Validation:** App will throw error if not configured in production
- **Environments:** Production, Preview, Development

**LOCATION_ID**
- **Value:** Your location UUID
- **Default (MVP):** `loc-00000000-0000-0000-0000-000000000001`
- **Note:** For single-location MVP, use the default
- **Environments:** Production, Preview, Development

## 🔧 RECOMMENDED ENVIRONMENT VARIABLES

These variables are recommended for production but have fallbacks.

### 1. API Security

**PARK_API_SECRET**
- **Value:** Strong random secret (32+ characters)
- **Generate:** `npx tsx scripts/generate-secrets.ts`
- **Example:** `6erFMswJS0hiktNNT24H0yXceVjC9PXP/s1kO//FGpc=`
- **Used for:** Admin API authentication
- **Environments:** Production, Preview

**ADMIN_API_KEY**
- **Value:** Strong random key (32+ characters)
- **Generate:** `npx tsx scripts/generate-secrets.ts`
- **Example:** `06Mxz64GSTGf6z6ZYtXcZJRtagSzvSYyqN46UZBaSJk=`
- **Used for:** Cleanup and maintenance endpoints
- **Environments:** Production

### 2. Web Push Notifications (VAPID)

**VAPID_PUBLIC_KEY**
- **Value:** VAPID public key
- **Generate:** `npx web-push generate-vapid-keys`
- **Example:** `BKxT...` (long base64 string)
- **Environments:** Production, Preview, Development

**VAPID_PRIVATE_KEY**
- **Value:** VAPID private key
- **Generate:** `npx web-push generate-vapid-keys`
- **Example:** `CmaF...` (long base64 string)
- **⚠️ KEEP SECRET:** Never expose this key
- **Environments:** Production, Preview, Development

**VAPID_SUBJECT**
- **Value:** `mailto:your-email@domain.com`
- **Example:** `mailto:admin@parkpos.pe`
- **Environments:** Production, Preview, Development

### 3. CORS Configuration

**ALLOWED_ORIGINS**
- **Value:** Comma-separated list of allowed origins
- **Example:** `https://parkpos.com,https://www.parkpos.com,https://app.parkpos.com`
- **Default:** `*` (allows all - not recommended for production)
- **Environments:** Production, Preview

## 🎯 OPTIONAL ENVIRONMENT VARIABLES

These variables are optional and have sensible defaults.

### Redis (Caching)

**REDIS_URL**
- **Value:** Redis connection string
- **Example:** `redis://default:password@redis-host:6379`
- **Default:** `redis://localhost:6379` (development only)
- **Note:** Highly recommended for production performance
- **Environments:** Production, Preview

### Logging

**LOG_LEVEL**
- **Value:** `debug` | `info` | `warn` | `error`
- **Default:** `info`
- **Recommendation:** `info` for production, `debug` for development
- **Environments:** Production (info), Preview (debug), Development (debug)

### OpenTelemetry (Observability)

**OTEL_EXPORTER_OTLP_ENDPOINT**
- **Value:** OpenTelemetry collector endpoint
- **Example:** `https://otel-collector.example.com:4318/v1/traces`
- **Default:** `http://localhost:4318/v1/traces`
- **Note:** Only needed if using distributed tracing
- **Environments:** Production, Preview

## 🔄 STEP-BY-STEP CONFIGURATION GUIDE

### Step 1: Generate Secrets
```bash
# Generate all secrets at once
npx tsx scripts/generate-secrets.ts

# Save the output in a secure password manager
```

### Step 2: Generate VAPID Keys
```bash
# Install web-push globally if needed
npm install -g web-push

# Generate keys
npx web-push generate-vapid-keys

# Output will look like:
# Public Key: BKxT...
# Private Key: CmaF...
```

### Step 3: Get Database Credentials
1. Go to Supabase Dashboard
2. Navigate to Settings → Database
3. Copy "Connection string" (Pooler mode)
4. **IMPORTANT:** If you previously exposed credentials, rotate them:
   - Click "Reset database password"
   - Copy the new connection string

### Step 4: Configure in Vercel
For each variable:
1. Click "Add New" in Vercel Environment Variables
2. Enter the **Key** (e.g., `JWT_SECRET`)
3. Enter the **Value** (paste the generated secret)
4. Select **Environments**:
   - Production: ✅ (always)
   - Preview: ✅ (recommended)
   - Development: ✅ (if needed)
5. Click "Save"

### Step 5: Verify Configuration
```bash
# Trigger a new deployment in Vercel
# The build should succeed if all required variables are configured

# Check the deployment logs for:
# ✅ No "CONFIGURATION ERROR" messages
# ✅ No "SECURITY ERROR" messages
# ✅ Build completes successfully
```

## 🐛 TROUBLESHOOTING

### Error: "CONFIGURATION ERROR: TENANT_ID must be configured"
**Solution:** Add `TENANT_ID` environment variable in Vercel

### Error: "SECURITY ERROR: JWT_SECRET must be configured"
**Solution:** Add `JWT_SECRET` environment variable in Vercel (generate with script)

### Error: "SECURITY ERROR: PIN_SALT must be configured"
**Solution:** Add `PIN_SALT` environment variable in Vercel (generate with script)

### Error: "Database connection failed"
**Solution:** 
1. Verify `DATABASE_URL` is correct
2. Check if database password was rotated
3. Ensure Supabase project is active

### Error: "VAPID keys not configured"
**Solution:** This is a warning, not an error. Add VAPID keys if you want push notifications.

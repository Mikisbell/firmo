## 💡 TIPS DE USO

### Formato Correcto
✅ **CORRECTO:**
```
"Continuar implementación Opción 3 desde FASE1 DÍA2"
```

❌ **INCORRECTO:**
```
"continuar opcion 3 dia 2"  // Falta formato
"Continuar Fase 1"          // Falta "Opción 3"
"Día 2"                     // Falta fase
```

### Palabras Clave Importantes
- **"Continuar"** - Para retomar
- **"Opción 3"** - Identifica el plan
- **"FASE1/FASE2/FASE3/TESTING/DEPLOYMENT"** - Identifica fase
- **"DÍA[X]"** - Identifica día específico

### Contexto Adicional (Opcional)
Puedes agregar contexto para mejor ayuda:

```
"Continuar implementación Opción 3 desde FASE1 DÍA2, 
ya completé rate limiting pero tengo dudas con CORS"
```
